# mcu_ato_relay_open

MCU 继电器控制与状态监测上位机 `mcu_ato_relay` 的公开版本信息仓。

功能简介：上位机通过串口每秒下发 12 字节帧，控制 VC5～VC8 四路继电器并读取 MCU 回执。指令模式支持循环吸合（默认吸合 10 分钟、断开 10 分钟，循环往复，时长可配）、自动切换 05/0A、保持 05、保持 0A。程序按分钟汇总各路最终状态与导通秒数，上传 MQTT 与 MariaDB，本地 SQLite 保留待传队列并自动重试。采集设置可配站点、串口、MQTT、数据库，密码 AES 加密保存。关于页「检查更新」读取本仓版本号。

本仓只放版本元数据，不提供 APK、安装包或脚本文件。

当前版本：**1.1.0**（2026-10-17）
